micro:bit: плата, яка вимірює й говорить по радіо

Сьогодні ти програмуєш справжній мікроконтролер — поки що в симуляторі. Найкращі програми вчитель завантажить у справжні плати наприкінці уроку.

makecode.microbit.org → New Project

Що вміє micro:bit V2. Ліворуч у MakeCode — симулятор: на ньому можна натискати кнопки, трясти плату, рухати повзунки температури, світла й звуку.

Місії

МІСІЯ 1

Візитівка

На старті плата пише твоє ім'я. Кнопка A — серце, B — усмішка, A+B — екран гасне.

Перевір: натисни в симуляторі A, B, а потім A+B (третя кнопка з'являється під платою).
Підказка: блоки

on start + show string · on button A pressed + show icon · clear screen (у More)

★ Намалюй власну картинку блоком show leds на кнопку логотипа on logo pressed.
МІСІЯ 2

Кубик

Струснув плату — випадає число від 1 до 6.

Перевір: кнопка SHAKE у симуляторі, 10 разів. Чи бувають 1 і 6? А 0 чи 7?
Підказка: блоки

on shake + show number + pick random 1 to 6

★ Замість цифри — крапки, як на справжньому кубику: set змінну, потім if … else if … і шість show leds.
МІСІЯ 3

Лічильник людей

A — зайшла людина (+1), B — вийшла (−1), A+B — обнулити. На екрані завжди поточне число.

Перевір: 5 разів A, 2 рази B → має бути 3.
Підказка: блоки

Variables → Make a Variable «count» · change count by 1 / by -1 · set count to 0 · show number count

★ Число не може бути менше за 0: if count > 0 then.
МІСІЯ 4

Термометр і світломір

Постійно показує температуру. Натиснув A — показує рівень світла.

Перевір: рухай у симуляторі повзунок температури (червоний) і світла (жовтий). Числа змінюються?
Підказка: блоки

forever + show number + temperature (°C) · on button A pressed + light level

Фізика. Датчик температури сидить у процесорі, тому справжня плата показує на 1–3 °C більше, ніж у кімнаті. А «рівень світла» 0–255 — не люкси, а умовні одиниці: щоб зробити з нього люксметр, плату треба відкалібрувати за справжнім приладом.
★ Термометр з тривогою: якщо температура вища за 30 °C — show icon ❗ і play tone.
МІСІЯ 5

Будівельний рівень

Плата лежить рівно — на екрані ✓. Нахилили ліворуч — стрілка ліворуч, праворуч — стрілка праворуч.

Перевір: веди мишкою над платою в симуляторі — вона нахиляється.
Підказка: блоки

forever + if … else if … else · acceleration (mg) x < −150 → show arrow West · > 150 → show arrow East · інакше show icon Yes

Фізика. Плата, що лежить, вимірює прискорення ≈ 1000 mg — це вільне падіння, яке їй «заважає» стіл: 1 g ≈ 9,8 м/с². Під час нахилу на кут α на вісь x припадає ax = g · sin α.
★ 10 клас: покажи сам кут у градусах. Зручніше в Python: math.asin(x / 1024) дає радіани, перевести в градуси — ×180/π. Чому краще ділити не на 1024, а на справжню силу тяжіння acceleration (mg) strength?
МІСІЯ 6

Час реакції

B — старт: екран гасне, через випадковий час 1–4 с з'являється мішень. Тиснеш A якнайшвидше — плата показує час реакції в мілісекундах.

Перевір: зіграй 5 разів, запиши найкращий результат. Скільки в сусіда?
Підказка: блоки

on button B pressed: clear screen → pause pick random 1000 to 4000 → show icon → set start to running time (ms). on button A pressed: show number running time − start.

Фізика. Авто їде 60 км/год ≈ 16,7 м/с. Поки водій реагує, воно проходить s = v · t. Порахуй свій шлях: при 250 мс це вже понад 4 метри — ще до початку гальмування.
★ Фальстарт: натиснув A, поки мішені ще немає — на екрані ✗, а не час.
МІСІЯ 7

Шумомір

Стовпчик на екрані росте разом із гучністю. Дуже гучно — сердите обличчя.

Перевір: повзунок звуку в симуляторі (з'являється, щойно використаєш блок звуку).
Підказка: блоки

forever + plot bar graph of sound level up to 255 · on loud sound + show icon Angry

Фізика. Мікрофон дає 0–255 — теж умовні одиниці, не децибели. Шкала децибелів логарифмічна: +10 дБ — це вдесятеро більша інтенсивність звуку.
МІСІЯ 8

Радіо

Кнопка A надсилає число по радіо. Плата, що його отримала, показує серце й посилає відповідь: усмішку.

Перевір: щойно додаси радіоблок, у симуляторі з'являться дві плати. Натисни A на одній — що на другій?
Підказка: блоки

on start + radio set group (номер скаже вчитель) · on button A pressed + radio send number 1 · on radio received receivedNumber + if receivedNumber = 1 → серце й send number 2; = 2 → усмішка

Фізика. Радіо micro:bit працює на 2,4 ГГц — як Wi-Fi і Bluetooth. Довжина хвилі λ = c / f ≈ 12,5 см. «Група» — це як канал: плати з різними групами одна одну не чують.
★ Камінь-ножиці-папір по радіо: струснув — випало 0, 1 або 2, плата показує свій знак і надсилає його. Отримала знак суперника — показує, хто переміг.
МІСІЯ 9

Компас

Плата показує літеру сторони світу: N, E, S або W.

Перевір: повзунок компаса в симуляторі. 0° — північ, 90° — схід.
Підказка: блоки

compass heading (°) у змінну · if менше 45 або більше 315 → show string "N" · і так далі для E, S, W

Фізика. Компас — це магнітометр: він вимірює магнітне поле Землі. Поруч з магнітом, динаміком чи залізом він бреше — справжню плату перед роботою калібрують, крутячи її в руках.
МІСІЯ 10 ★
